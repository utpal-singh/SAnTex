# Keyboard Shortcuts

## Global shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+O` | Open EBSD file |
| `Ctrl+Q` | Quit application |

## Plotly chart interactions

| Action | Effect |
|--------|--------|
| Left click + drag | Pan |
| Scroll wheel | Zoom in / out |
| Double-click | Reset zoom to default |
| Hover over point | Show tooltip (X, Y, value) |
| Box-select (drag from top-left) | Zoom to selection |
| Camera icon (toolbar) | Export current view as SVG |
| Home icon (toolbar) | Reset all axes |
| Lasso select | Select data points |
| Toggle trace (legend click) | Show / hide individual traces |

## PyVista 3-D viewport

| Action | Effect |
|--------|--------|
| Left drag | Rotate scene |
| Right drag | Zoom |
| Scroll wheel | Zoom in / out |
| Middle drag | Pan |
| `r` key | Reset camera to default view |
| `f` key | Fly to point under cursor |
| `s` key | Surface rendering |
| `w` key | Wireframe rendering |
| `p` key | Pick a point (show coordinates) |

## Table navigation

| Action | Effect |
|--------|--------|
| Click row | Select mineral / grain |
| Click column header | Sort by column |
| `Ctrl+C` | Copy selected cell text |
